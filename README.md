## 课程项目

### 人民币汇率波动的宏观驱动因素研究

**项目概述**：本项目旨在分析人民币汇率波动的宏观驱动因素，基于CPI、PMI、名义广义美元指数与社会事件等多维度数据，通过时间序列分析和事件研究法，探索各因素对人民币汇率的影响。

**项目内容**：
- 数据获取与处理：从FRED API获取宏观经济数据，合并多源数据
- 可视化分析：人民币汇率与美元指数的时间序列分析、滚动相关性分析
- 事件研究：分析不同类型事件对人民币汇率的影响
