# RNN歌词生成器

这是一个使用循环神经网络(RNN)生成歌词的教学案例。该项目展示了如何使用PyTorch构建和训练一个基于LSTM的文本生成模型。

## 项目结构

```
rnn_lm/
├── lyrics_dataset.txt    # 歌词数据集
├── model.py             # RNN模型定义
├── train.py             # 训练脚本
├── generate.py          # 歌词生成脚本
├── requirements.txt     # 项目依赖
└── README.md            # 项目说明文档
```

## 环境要求

- Python 3.7+
- PyTorch 1.9+
- NumPy 1.21+

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 训练模型

运行训练脚本来训练RNN模型：

```bash
python train.py
```

训练参数可以在`train.py`中调整：
- `epochs`: 训练轮数 (默认: 100)
- `batch_size`: 批次大小 (默认: 64)
- `learning_rate`: 学习率 (默认: 0.001)
- `seq_length`: 序列长度 (默认: 25)
- `embedding_dim`: 词嵌入维度 (默认: 128)
- `hidden_dim`: 隐藏层维度 (默认: 256)
- `num_layers`: LSTM层数 (默认: 2)

训练完成后，模型将保存为`lyrics_rnn_model.pth`文件。

### 2. 生成歌词

训练完成后，可以使用生成脚本来生成歌词：

```bash
python generate.py
```

生成脚本将使用不同的温度参数生成歌词，并提供交互式界面供用户自定义种子文本、生成长度和温度参数。

温度参数说明：
- 低温度 (如 0.5): 生成更确定性和保守的文本
- 中温度 (如 1.0): 平衡创造性和一致性
- 高温度 (如 1.5): 生成更多样化和创造性的文本

## 模型架构

该模型基于LSTM架构：
1. **词嵌入层**: 将字符转换为向量表示
2. **LSTM层**: 处理序列数据，捕捉长期依赖关系
3. **全连接层**: 将LSTM输出映射到词汇表大小
4. **Softmax层**: 输出每个字符的概率分布

## 数据集

`lyrics_dataset.txt`包含了一些示例歌词，用于训练模型。在实际应用中，您可以替换为更大的歌词数据集。

## 教学要点

1. **文本预处理**: 如何将文本数据转换为模型可处理的格式
2. **序列建模**: 使用LSTM处理文本序列
3. **字符级语言模型**: 基于字符而不是词汇的生成
4. **温度采样**: 控制生成文本的创造性和多样性
5. **模型保存与加载**: 如何保存训练好的模型并在后续使用

## 扩展建议

1. 使用更大的歌词数据集进行训练
2. 尝试不同的RNN架构 (GRU, 多层LSTM)
3. 实现词汇级而不是字符级的模型
4. 添加注意力机制
5. 使用预训练的词向量 (如Word2Vec, GloVe)
